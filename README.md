Oddsdata kan importeras till inputs/quotes.csv med följande kolumner:
sport,event,market,line,outcome,bookmaker,odds,source,observed_at,role
role: offer eller reference. observed_at: tidsstämpel i ISO-8601 UTC, t.ex. 2026-11-13T12:00:00Z.
Reference måste ha alla ömsesidigt uteslutande utfall i samma marknad. Minst två separata referenskällor krävs.
OBS: Publikt GitHub-repository gör inputs/quotes.csv offentlig. Lägg INTE upp privata data, nycklar eller licensbelagda datamängder i öppet repo. Använd endast data du får publicera.
